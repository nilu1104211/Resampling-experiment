# OUNet 坐标域错误与 60 轮训练重启

日期：2026-11-03，北京时间。

## 服务器错误与复现

服务器的正式训练使用 `batch=8`、`epochs=60`、`octree_scale=0.5`。训练在 epoch 0、第 1530 个 batch 中断，异常来自 GT 八叉树构建，不是学习率调度。

本机用相同 V3 数据与 epoch 顺序复现了该样本：

- batch slot：3；dataset index：10336；原始 source index：20672。
- base：`pu1k/03261776.4262c3dbd68a5c14957b6a4f3924d982/train/patch_000`。
- 退化类型：`online_hole`。
- 公共输入归一化后，输入最大绝对坐标约 `0.861085`，GT 最大绝对坐标 `2.0793187618`，GT 最大半径约 `2.144581`。
- 原 `0.5` 缩放后 GT 最大绝对坐标达到 `1.03965938`，超出八叉树要求的严格 `(-1, 1)`。

公共归一化只统计实际输入。缺口改变实际输入的中心和半径后，未缺损 GT 可能落在输入单位球之外，这是合法的共同数据，不应删除异常样本或裁剪 GT。

11-02 的少量 batch 冒烟检查没有覆盖该样本。现在增加完整训练计划的域预检，避免用少量 batch 推断整个训练集范围。

## 修复方式

本次重启统一使用固定 `--octree-scale 0.25`，训练和后续推理必须一致。输入与 GT 共用此尺度，公共 V3 归一化、共同 256 点输入、1024 点 GT、每对象 32 个 patch、mixed 在线退化、旋转和原 OUNet 损失均不改变。尺度是整次实验固定的超参数，GT 不参与逐样本缩放或推理。

八叉树深度仍为 8，因此降低 scale 也会使公共坐标系中的格子间距增大；这是本次 OUNet-V3 配置的明确变化，需与训练结果一起记录，不能称为原生官方配置。

Adapter 越界异常现在会报告 input/GT、scale、原坐标峰值、缩放后峰值和 batch slot；仍不裁点、不动态修改 scale。

训练在第一轮尚未完成时退出，入口只在每轮结束后写 `last.pt`。本次应在新目录从头训练；不能用旧 `scale=0.5` 或调试权重直接 `--resume` 成新配置。

## 预检工具

`tools/check_ounet_domain.py` 对计划中的每个 epoch、每个共同训练 patch 生成与原训练完全一致的观测，使用公共输入均值和最大半径建立旋转无关的保守界：

`max ||GT - input_mean|| / input_radius <= (max ||GT|| + ||input_mean||) / input_radius`

界中加入 float32 数值余量，同时覆盖输入单位球。通过意味着所检查计划内的坐标在任意训练旋转下都落在域内；保守界失败不一定代表实际旋转后越界，工具会明确标为 `failed_conservative_bound`。

快速坐标路径复用原 `corrupt_base` 的选点、退化和 RNG，只跳过不需要的参考标签与质量统计。原训练路径保持默认行为；测试比较了全部固定条件及 60 个在线 epoch 的输入与 GT，结果逐点一致。

服务器如需重新核对相同计划，可运行：

```bash
python -u -B tools/check_ounet_domain.py \
  --root "$V3_DATA_ROOT" \
  --epochs 60 --octree-scale 0.25 \
  --training-mode mixed --train-patches-per-object 32 \
  --output server_runs/checks/ounet_domain60_scale025_20261103.json
```

本工具只验证坐标域，不验证训练收敛或重建质量。数据选择、训练模式、训练 horizon 或公共归一化改变后，应重新预检。

## 正式重启命令

先更新 Git。下面是全新的输出目录，保留此前失败日志；正式训练不加 `--max-batches`。

```bash
cd ~/baseline_compare
git pull --ff-only origin main
conda activate scdata-v3
source env_v3.sh

RUN_DIR=server_runs/patch32/ounet_b8_poly60_scale025_seed21
mkdir -p "$RUN_DIR"

nohup bash compare-change/run_v3.sh ounet train \
  --device cuda --seed 21 \
  --batch-size 8 --workers 0 \
  --training-mode mixed --train-patches-per-object 32 \
  --epochs 60 --ounet-schedule-epochs 60 --ounet-poly-power 0.9 \
  --lr 5e-4 --weight-decay 0.05 \
  --octree-depth 8 --octree-scale 0.25 \
  --output "$RUN_DIR" \
  > "$RUN_DIR/console.log" 2>&1 < /dev/null &

tail -f "$RUN_DIR/console.log"
```

`Ctrl+C` 只退出日志查看。最终权重是该目录的 `last.pt`，不会自动选 best。推理时必须显式传 `--octree-depth 8 --octree-scale 0.25`；CLI 的历史默认 scale 仍为 0.5，不会自动从 checkpoint 改写配置。
