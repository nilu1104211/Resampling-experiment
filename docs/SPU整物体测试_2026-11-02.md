## 服务器检查权重并后台测试

在 GPU 空闲时执行。后台任务使用 `nohup`，退出当前终端后仍可运行；同一输出目录已完成的条件会复用。检查或后台日志报错时，应先读取错误，不重新训练或改成 legacy/native 模式绕过检查。

```bash
(
set -euo pipefail
conda activate scdata-v3
cd ~/baseline_compare
git pull --ff-only
source env_v3.sh
export CUDA_VISIBLE_DEVICES=0

if pgrep -af '[r]un_subset_eval.py.*(--models spu|--worker spu)'; then
  echo "已有 SPU 评测进程，请勿重复启动。"
  exit 1
fi

EVAL_OUT="$PWD/server_runs/whole_object_eval80_spu_20261102"
EVAL_ARGS=(
  --models spu
  --spu-checkpoint "$PWD/server_runs/patch32/spu_shared256_b8_w0_cos60_seed21/last.pt"
  --root "$V3_DATA_ROOT"
  --whole-data-root "$PWD/modelnet40_object80_seed21"
  --objects 80 --seed 21
  --fps-backend cuda --patch-batch-size 1
  --output "$EVAL_OUT"
)

python -u -B run_subset_eval.py "${EVAL_ARGS[@]}" --phase check
mkdir -p "$EVAL_OUT"
nohup python -u -B run_subset_eval.py "${EVAL_ARGS[@]}" --phase run \
  >> "$EVAL_OUT/console.log" 2>&1 < /dev/null &
echo "SPU 评测已启动，PID=$!"
echo "日志：$EVAL_OUT/console.log"
)
```

检查要求：V3、`epoch=59`（完成 60 轮）、非 debug、`model_name=spu-imr`、`training_mode=mixed`，以及 `shared-v3`/64 组/source/8 次恢复的配置。训练指纹和 256 点共同观测预算由公共 preflight 核对。未训练完的 `last.pt` 会被拒绝，不会自动继续训练。
