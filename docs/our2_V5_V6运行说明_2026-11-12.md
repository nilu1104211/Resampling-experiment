# Our2 V5/V6 第一批验证

这一批使用现有 checkpoint 做推理验证。V6 冻结 PUFM-60 flow，只加载现有 M2 的独立预算头。V5 使用完整的 M1 最优 checkpoint，包括已适配的 flow。V4/V6-FT、V5-2、Joint 和多 seed 复验由本轮证据决定。

## V6 如何控制实际种子改动

- `D0` 原样返回 Midpoint 的种子及顺序。身份阶段只跑 D0，因此不构建候选池或重新 FPS。抽查 Patch、PU1K 和 ModelNet40 的七种条件各一例，必须逐点复现原路径，预测哈希必须与历史记录一致。
- `D1-L`、`D2-L`、`D3-L` 的 `(λ, ρmax)` 分别是 `(0.25, 0.05)`、`(0.50, 0.10)`、`(0.75, 0.10)`。Patch 为 8 区和 1024 点，整物体为 64 区和 8192 点。
- 学习和均匀组共用基于输入的 FPS 锚点、最近锚点分区和原 GDBA 候选生成规则。候选去重后全局排除原始种子坐标，再按实际最近锚点归区。配额上下界包含原始区域点数，以免某区的原始点数超出名义范围时被迫大幅修改。
- 两侧按目标差值分配同一个整数转移量。减额区用 FPS 保留覆盖，增额区从共享候选池用局部最远距离贪心补点。所有未删除种子保持原坐标及位置，新增坐标放进删除位置。逐样本检查点数、配额、去重和实际坐标替换数。
- `U` 组请求对应 `L` 组实际转移的点数。如果沿均匀目标方向可转移的量不足，则缩小并记录差额。配对差值表只使用实际转移量和坐标替换数都相同、且有非零改动的样本。

Patch 先跑 D0 和三个学习组。筛选阈值在运行前固定为总体及 A0、D7、E2 的 F-score 相对下降不超过 1%、CD-L1 相对上升不超过 1%、HD 相对上升不超过 2%。通过筛选且预算不同的候选按总体 F-score、CD-L1 排序，最多选两组补配对均匀组。整物体回归要求 Patch 实际改动量的匹配率至少 95%，并存在非零改动的配对样本。若无候选晋级，整物体阶段只保存固定示例，不做全量回归。阈值用于本轮研发筛选，正式统计需考虑对象配对和训练 seed。

## V5 开关的实际含义

`M1-full`、`M1-r`、`M1-h`、`M1-off` 沿用原 `refine` 的两个布尔开关。关闭可靠性时使用均匀邻居权重并关闭不可靠度位移，关闭孔洞时关闭候选引导。 `M1-no-move` 保留正常的头部计算，直接给 flow 原始 Midpoint。当前模型的两个头只通过种子位移影响 flow，因此 off 和 no-move 应等价，身份阶段会检查。

先跑 21 个身份样本，再跑完整 Patch。任一开关组与 full 的总体孔洞距离相对差异达到 1% 时，自动跑两个整物体回归集，否则只保存固定示例。输出包含位移、孔洞邻域与其他位置的差异、`r/h` 分位数、离群点和其余点的可靠度均值。候选孔洞诊断中，候选最近的 GT 点属于孔洞且距离不超过区域尺度时记为正例，报告候选 AP 及 0.5 阈值下的召回和误报。GT 和标签只参与预测之后的评分与诊断。

## 服务器运行

使用原训练环境 `scdata-v3`。入口会检查 V0 记录中的起始权重、数据、源码和运行环境。已有 V0–V3、初版训练及整物体结果目录保持可访问。

```bash
cd /home/zk/baseline_compare
conda activate scdata-v3
export CUDA_VISIBLE_DEVICES=0
mkdir -p server_runs/our2_logs

nohup python -u -B tools/our2_v56.py all \
  >> server_runs/our2_logs/v56_from60_seed21.log 2>&1 </dev/null &
echo "V5/V6 PID: $!"
```

`all` 依次跑 V6、V5，阶段内自动按身份检查、Patch、回归的顺序执行。也可单独指定 `v6` 或 `v5`。正式输出为 `server_runs/our2_v56_from60_seed21/`。修改源码、数据或筛选参数后使用新的 `--output`。同身份的已完成阶段会跳过。

用装有 Matplotlib 的 Python，从仓库根目录将下载的示例画成同视角图：

```powershell
python -B tools/plot_our2_v56.py "D:\dkwork\scdata\server_runs\our2_v56_from60_seed21" --output "D:\dkwork\baseline_compare\outputs\our2_v56_visuals"
```

每个整物体数据集固定两个对象，保留 A0、C2、D7、E2 的输入、GT、原种子、改动种子和最终输出。回归集用于固定协议复查，最终独立测试留到 V8。
