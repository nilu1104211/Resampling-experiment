## 已处理的问题

- WRS batch=1 索引维度与合法无放回点数；独立采样 RNG。
- FFPS 原 CUDA `clock64()` 随机性；稳定排序使用 keyword-only `dim` 参数。
- CUDA `median(...).values` 在严格确定性模式下仍依赖非确定性索引实现：改用稳定排序取中位值，不关闭确定性检查。
- NMM noisy 路径改用有几何含义的局部邻域顺序；训练干净对应索引匹配、teacher detach。
- SPO 评分添加显式监督；补全锚点保留固定名额；投影改为 batch/点数归一化的训练正则。
- 保存第 0 轮状态、原子写 checkpoint、先提交 best 再提交 last；中断验证可以在相同身份下重做。
- 训练队列直接启动实际训练入口，避免 Linux 停止 dispatcher 后训练进程继续运行。
