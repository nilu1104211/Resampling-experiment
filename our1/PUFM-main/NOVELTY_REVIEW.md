# RGR/MGB 新颖性审查与待验证命题

审查日期：2026-10-22。依据用户 v2 方案、本轮实际实现、相关工作的公开论文摘要/项目资料及针对 marginal gain / counterfactual point-cloud allocation 的检索。这是局部研究审查，尚未完成全部相近全文的逐公式查新。

## 判断

**机制层面比 v1 的“特征打分＋Softmax”更有区分度，有形成研究贡献的空间；当前不能断言创新已经充分、已经首次提出，或可以保证达到某个发表层级。**

当前最可辩护的核心是：固定输出点数下，通过对同一候选池进行配额交换，监督“经过具体生成器以后”的相对几何收益，再根据受体收益与供体机会成本决定配置。RGR 作为收益判断的可靠几何输入和恢复候选来源，属于支撑机制；一般条件融合与计数正则不宜各自包装成强创新。

## 与公开思路的重合和区分

| 部分 | 已有思路／重合 | 当前实现可研究的区别 | 当前强度判断 |
|---|---|---|---|
| 多尺度编码、q、ΔX | 去噪、可靠性加权是已有方向 | 是否减少噪声导致的错误预算，并保留真实边缘 | 单独不足以构成强创新 |
| h/r/V/u | 遮蔽恢复、候选查询、风险估计已有大量相关思路 | 可恢复性是否改善预算收益预测和小孔洞几何 | 需独立实验证实，不能用模块名代替新机制 |
| 保底＋动态点数 | CADD-PCN 已研究固定预算子点分配、责任监督、欠观测需求和保底配额 | 从 GT 责任目标转为实际生成后预算交换的误差差值 | 这是必须直接比较的差别 |
| 学习局部细节／覆盖折中 | SAMBLE 已研究形状相关的学习采样与细节/均匀性折中 | 本项目针对新增点生成及后续 PUFM，而非仅已有点下采样 | 单纯“重要区域多给点”不能作为创新 |
| 密度＋FM | PURF 相关方向已被方案指出，需继续核对其全文 | 生成器相容的交换收益，而非仅密度条件 | 不将“密度进入 FM”列为独立主贡献 |
| 鲁棒 FM | PUFM++ 已包含两阶段 FM、RIN、时间调度和流形约束 | 显式区域数量决策与收益解释 | 鲁棒性提高本身不是新机制证明 |
| 递减收益曲线和交换优化 | 边际收益、凹效用与资源配置是一般优化概念 | 针对该任务的监督构造、生成器条件和可验证效果 | 不能把曲线公式或贪心算法声称为数学首创 |

## 必须证明的四个命题

1. **真实交换收益可预测。** 留出物体上的收益排序、正负判断、选择后实际改善应优于随机／符号多数基线。训练集 Huber 降低不够。
2. **预算依赖有独立价值。** 与相同特征、相同训练期教师、相近参数量的 static 头比较；在不同起始配额和 Δ 上验证，不只在统一 m=24 的一个点上拟合。
3. **RGR 增加的是决策质量。** 除最终 CD，还要看错误高密度分配、孔洞区几何、噪声边缘保持；RGR+static 对 RGR+MGB 是重要对照。
4. **代价合理。** 同时报告教师构建积分次数、在线交换额外训练成本、推理全链路时间和显存。改善来自额外监督／训练计算的部分应坦诚记录。

同一原始 GT 可以用于常规几何损失与训练期交换监督，不要求更换为非均匀目标。最终以独立测试原 GT、真实 Mesh P2F、覆盖和区域质量评价。不能因为输出密度变均匀就判定预算无效，也不能因为密度保持就声称几何更好。

## 当前理论与实现限制

- 交换教师直接约束相对收益差，通常不能唯一识别每个区域的绝对收益曲线。a/β/γ 应解释为相对收益代理的参数，不能解释为已经识别的物理量或绝对最优效用。
- 实际生成误差存在跨区域相互作用；可加、非负且单调递减曲线只是函数族假设。拟合不足时，应与无约束成对头或分段表比较，而不是只增加曲线复杂度。
- 这是确定性配置干预形成的训练监督，不等同于已建立正式因果识别理论。“反事实预算交换”应说明具体操作，不扩张为一般因果发现主张。
- r/u 使用可见支持与 GT 样点误差的弱代理；当前不是已证明校准的真实可恢复概率／完整不确定性模型。无独立收益时应删掉对应分支。
- 巨大孔洞超出局部观测可识别范围时，有限偏移查询无法保证补全；低可靠输入也可能使中点池塌缩或产生重复点。首版保持点数与有限值，不宣称所有输入都能产生不同坐标的真实表面点。
- 正常输入、非均匀、缺失、噪声和组合条件必须完整报告，不选择性展示有利指标。完整 FM 的作用由最终误差和覆盖验证，不先预设其与均匀 GT 必然冲突。

## 建议的贡献表述

“针对固定点数的点云生成，构建共享候选池上的训练期预算交换，以生成后几何误差变化监督相对边际收益，并结合可靠几何与缺失恢复查询完成受约束的区域预算决策。”

若 MGB 在留出物体上不能超过 static／规则预算，当前工作主要仍是系统组合与工程改进；若收益排序、最终几何与模块互补均成立，才有更强的机制贡献证据。本轮实现提供了这些检验接口，尚未提供性能或新颖性已经成立的结论。
