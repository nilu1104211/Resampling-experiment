# 基于 PUFM 的自适应重采样：双自主模块细化设计方案

> **版本**：V1.0（2026-11-11）  
> **研究对象**：公共点云数据上的自适应重采样；以原始 PUFM 为唯一修改主干  
> **核心模块**：M1 可靠性感知与缺失引导恢复（RAGR）＋ M2 重建需求驱动的动态点数分配（GDBA）  
> **性质**：**待验证的工程与研究设计稿**，不是已经实现、已训练或已证明独创性的结果。  
> **范围边界**：公共数据实验不引入焊接熔池物理模型；不额外引入第三个创新模块；不继续在旧 Ours / Our1 的模块上修修补补。

---

## 0. 一页摘要：最终决定

1. **主干保留 PUFM**：保留原始特征提取、基于 Midpoint 的稠密初始化和流匹配（Flow Matching, FM）生成框架。新增模块优先作为小幅残差或条件分支，而非重写速度场主干。
2. **M1 解决“哪里不可信、哪里可能缺失、应往哪里恢复”**：输出输入点可靠性 `r_i`、候选缺失区域恢复需求 `h_j`、受约束的恢复方向或条件特征，影响初始化和 FM 的条件输入。**M1 单独运行时不改变区域输出预算。**
3. **M2 解决“固定 N 个输出点怎么分给不同区域”**：利用区域特征预测预算 logits / 连续预算，加入覆盖保底、分配上限和精确整数化，在 Midpoint 初始化前完成预算分配。**M2 单独运行时不得依赖 M1 的输出。**
4. **联合时只做一个轻量接口**：M1 的可靠性和恢复需求作为 M2 的附加条件；保留 M2 对几何与上下文特征的独立判断。避免重新形成复杂的多阶段 GainNet / 教师链条。
5. **监督保持干净 GT 为统一几何参照**：可在训练时借助 v3 退化记录构造点可靠性与缺失监督；测试时绝不读取 GT、缺失掩码或退化生成标签。
6. **先修好续训对照**：已观察到 15 轮 B-extra 自身明显退化，若直接在此基础上判断新模块，会混淆训练策略与模块本身的贡献。
7. **评价不只看 CD**：以 CD-L1、F-score、HD 为主，分解 7 种退化条件，并加入孔洞区域覆盖、噪声残留、预算实际分布与运行速度分析。

**核心逻辑**：M1 判断“重建需求在哪里”，M2 判断“有限点数怎样合理配置”，PUFM 负责“生成高精度点坐标”。

## 1. 研究依据与证据等级

### 1.1 已完成实验的真实测试口径

- 数据集：PU1K、ModelNet40；每个数据集固定 **80 个整物体**。
- 7 种退化：`A0_normal`、`B2_sparse_mid`、`C2_hole_10`、`D2_noise_005`、`D7_outliers_02`、`E1_mixed`、`E2_mixed_outliers`。
- 测试每个配置、每数据集 **80 × 7 = 560** 个样本；2048 点输入、8192 点输出。
- 训练曾使用 256→1024 的 Patch 口径；测试跨到 2048→8192 的整物体口径。
- 主汇总：先在物体内计算指标，再对 7 个条件等权聚合；**这是当前冻结子集而非官方全量测试**。
- 本次模块实验只有 **单个 seed**，不同批次存在继续训练预算与模型选择差异。

### 1.2 实验结果一览

| 对象 | PU1K CD-L1 ↓ | ModelNet40 CD-L1 ↓ | PU1K F-score ↑ | ModelNet40 F-score ↑ | 可信结论 |
|---|---:|---:|---:|---:|---|
| PUFM（本次重测） | 0.018082 | 0.019988 | 0.2885 | 0.2235 | 当前直接比较基线 |
| M1a 终点 CD | 0.017868 | 0.019849 | 0.2583 | 0.1990 | CD 略改善，F-score 明显退化 |
| **M1b 终点 CD＋初始化扰动** | **0.017081** | **0.018788** | **0.2891** | **0.2270** | 两个数据集 CD 改善约 5%–6%，F-score 基本保持/略改善 |
| M2a 终点 APML | 0.017140 | 0.018897 | 0.2746 | 0.2129 | CD/HD 改善，F-score 下降 |
| 冻结 PointSP-LGP | 0.017928 | 0.019930 | 0.2807 | 0.2166 | CD 轻微改善，但 F-score、HD、耗时付出代价 |
| PUFM++（历史完整模型） | 0.014618 | 0.016408 | 0.4005 | 0.3046 | 当前完整网络中综合表现突出 |
| SPU-IMR（历史完整模型） | 0.016509 | 0.018453 | 0.3830 | 0.2921 | F-score 优势明显，但对当前显式空洞退化并非全优 |
| Our1（历史完整模型） | 0.018379 | 0.019743 | 0.2458 | 0.1956 | 某些覆盖距离改进，阈值精度未同步改善 |

**来源与限制**：M1a/M1b/M2a 取 2026-11-11 的《独立模块整物体测试结果与网络对比》；历史完整模型取此前《六模型实验现状与新对话交接》（2026-11-05）并在 11-11 汇总中再列出。历史模型和本次新模块虽采用相同冻结对象协议，但运行环境、后端、训练过程可能不同，不能把所有差异归因于网络结构。

### 1.3 每条结果在设计中的正确用法

| 结果 | 能支持的启示 | **不能**推出的结论 |
|---|---|---|
| M1b | 初始化与终点训练目标协同调整有潜力 | “扰动初始化必然适合动态分配”或“它已学会自适应点数预算” |
| M2a | 降低某些几何误差并不保证 F-score 提高 | “只要 CD 降低就说明覆盖恢复成功” |
| 15 轮采样实验普遍不佳 | 固定密度/曲率等规则在当前适配中缺少优势 | “动态点数分配本身不可行” |
| 15 轮 B-extra 退化 | 必须校验续训和 checkpoint 选择 | “所有 15 轮候选的结构均无效” |
| PUFM++ 优势 | 整体方案的初始化、训练与生成协同很重要 | “某一个单独的 PUFM++ 模块带来了全部收益” |
| SPU-IMR 优势 | 利用可见部分推断缺失结构值得借鉴 | “随机 mask 恢复一定能处理输入固有孔洞” |
| Our1 F-score 下降 | 预算/恢复不能只优化平均覆盖距离 | “增加孔洞候选点必然损害其他区域” |

### 1.4 PUFM++ 和 SPU-IMR 的参考边界

**PUFM++（原论文）**：两阶段流匹配、终点扰动精修、自适应时间安排、流形约束与特征交互强化是其公开描述的主要技术路线。本地评测版本还包含**局部 256 点块、6 步生成、后处理和校准时间表**。本设计仅借鉴“扰动下的稳健生成”和“几何约束参与生成”的原则，不复制整个网络/时间表/后处理。

**SPU-IMR（原论文）**：把上采样视为形状补全，利用可见 Patch 逐步恢复被遮蔽 Patch；本地评测使用**局部 256 点块、64 组、source transport、8 次恢复、密度过滤与合并**。本设计借鉴“基于可靠上下文预测缺失结构”，不复制迭代 Mask-recovery 网络。

**关键实验事实**：SPU-IMR 在本次历史空洞条件下，PU1K `0.019051 > PUFM 0.018914`，ModelNet40 `0.021094 > PUFM 0.020954`（CD 越低越好），所以 M1 必须针对**真实输入缺失**构造训练监督与消融，而不是只做随机 mask 恢复。

## 2. 总体架构及 I/O 合同

### 2.1 数据流

```text
输入 X ∈ R^(B×n×3) ──► 原 PUFM 特征编码器 ──► F ∈ R^(B×n×C)
       │                                  │
       │                                  ├──► [M1 / RAGR] ──► r_i, h_j, Δx_i, c_i
       │                                  │                          │
       │                                  └──► [M2 / GDBA] ◄──────────┘ （联合模式）
       │                                           │
       │                                区域预算 {B_j}, sum(B_j)=4n
       │                                           │
       └────────► 原 Midpoint 候选初始化 ──► 预算选择/轻微种子修正 X_0
                                                         │
                                                  PUFM 速度场 v_θ
                                                         │
                                                     流积分生成
                                                         │
                                                  输出 Y ∈ R^(B×4n×3)
```

**开关约束**：
- `baseline`：两个模块关闭，预测必须与原始 PUFM 等价（允许数值浮点误差）。
- `m1_only`：`r/h/Δx/c` 有效，但区域预算维持原始初始化分布，输出总点数不变。
- `m2_only`：区域预算可变，但不使用 `r/h/Δx/c`；从原 PUFM 特征和几何信息自主分配。
- `joint`：M1 的可靠性与缺失需求可以进入 M2 特征，但需保留独立的 M2 分支。

### 2.2 尺寸自适应配置（**建议起点，需在验证集确认**）

| 参数 | Patch 训练 | 整物体测试 | 说明 |
|---|---:|---:|---|
| 输入 n | 256 | 2048 | 使用现有 v3 口径 |
| 输出 N | 1024 | 8192 | 固定 4 倍上采样 |
| FPS 锚点区域 K | 8 | 64 | `K=ceil(n/32)`，使每区平均覆盖规模接近 |
| 每区平均输出预算 N/K | 128 | 128 | 便于跨点数尺度迁移；非实际刚性均匀约束 |
| 基础预算比率 α | 0.5 | 0.5 | 示例 `b_min≈64` 点/区；后续消融 |
| 每区预算上限 | 约 2×均值 | 约 2×均值 | 仅为第一版安全范围 |
| M1 邻域规模 | k=16、32 | k=16、32 | 固定邻居数 + 尺度归一化特征；需防分布漂移 |
| FM 积分 | 原基线设置 | 原基线设置 | **先不要更换推理时间表** |

区域锚点在输入点云上确定；**区域归属应唯一**，但为提取邻域特征可以使用重叠 KNN。测试时不能偷偷给模型额外 GT 点或额外观察点。若整物体使用 patch 内归一化，需要先核对现有 PUFM 的 canonical 坐标与反归一化流程。

## 3. 模块一 M1：可靠性感知与缺失引导恢复（RAGR）

### 3.1 职责与设计原则

**目标**：在不额外重写 PUFM 主干、不改变总预算的情况下，使 PUFM 更能处理噪声、离群点、稀疏和孔洞。

M1 不是“噪声二分类头＋普通补洞头”的简单相加。二者需要共享局部几何与跨区域上下文：

1. 点**可靠性**：输入点是否位于可信的局部几何结构上？
2. 区域**恢复需求**：候选区域是否有证据表明存在观测不足或缺失？
3. **恢复方向与置信度**：应把生成种子往什么局部几何方向移动？若证据不足应降低修正幅度。

### 3.2 输入与输出

**输入**：
- `X: [B,n,3]`：有退化的观测点云；
- `F: [B,n,C]`：PUFM 编码特征（尽量复用，避免再造完整骨干）；
- 可计算几何描述 `G`: 多尺度局部密度、PCA 特征值比、局部法向一致性、相邻 Patch 的上下文差异、邻域尺度。

**输出**：
- `r: [B,n,1]`：每点可靠度，区间 `(0,1)`；
- `h: [B,K,1]` 或候选恢复锚点的需求分数；
- `d: [B,N,3]`：对插值种子的受限位移方向；
- `c: [B,N,Cc]`：供 PUFM 速度场使用的轻量条件特征。

> 注意：原始孔洞内部通常没有输入点，不能仅通过逐点 `r_i` 检测缺失；需要从可见边界与相邻区域产生**候选锚点**，再判断是否需要恢复。

### 3.3 推荐的内部结构

**A. 多尺度几何关系编码（共享）**

- 复用 PUFM 的点特征，补充小型 KNN 局部相对坐标编码：`Δx_ij`、归一化邻距、局部尺度、法向/曲率代理量；
- 对 k=16 和 k=32 两个邻域提取均值/最大池化信息；
- 用轻量 MLP/门控融合（不新建整套大 Transformer）。

**B. 可靠性头 `r_i`**

\[
r_i=\operatorname{sigmoid}(f_r([F_i,G_i,G_i^{context}]))
\]

不直接按阈值删除所有低 `r_i` 点：真实尖锐边、细杆、稀疏边界也可能在局部看来不一致。优先把 `r_i` 用于**弱化特征污染、降低噪声点对插值方向的影响**；只在验证证明有效时再加入硬删除。

**C. 候选恢复区域头 `h_j`**

- 使用 FPS 锚点覆盖观测表面，并基于**多尺度异常间隙**、相邻 Patch 连接关系提出候选恢复锚点；
- 在候选点的邻域两侧收集可靠上下文，计算结构连贯性；
- 判断候选是“真正的观测缺失”还是“物体自然边缘/开口/两层不相连的表面”；
- 输出恢复需求和不确定度。对无充分跨侧信息的区域，使用保守恢复策略，避免凭空补出不存在的面。

候选位置生成可以先从**邻域几何外推＋切平面约束**实现，但必须控制最大外推距离；第一版不用复杂的新独立补全网络。复杂拓扑区域的候选产生是**主要技术风险点**，需要可视化验证。

**D. 小幅恢复引导 `d` 与条件 `c`**

\[
X_0'=X_0+\gamma\,g(r,h)\,\operatorname{clip}(d,\delta_{max}),\qquad \gamma\text{ 初始为 }0
\]

其中 `X_0` 为原 PUFM Midpoint 初始化，`g(r,h)` 为置信门控；`γ=0` 初始化使改进网络**初始行为与 PUFM 对齐**，再逐渐学习小幅修正。`δ_max` 应采用局部邻域尺度而非固定全局数值。

若速度场已有条件接口，可以使用残差条件注入：

\[
\hat v=v_{PUFM}(x,t,F)+\eta\,\Delta v(x,t,c),\quad \eta\text{ 初始为 }0
\]

**第一版只选择一种主接入方式**（种子修正优先）；确认有收益后再尝试速度场条件注入，避免无法归因。

### 3.4 监督标签：必须避免自我循环

**可靠性标签**：优先使用 v3 数据生成时保存的噪声/离群点索引或点来源标记。若现有 v3 未保留，先检查元数据是否能按原退化 seed 无损重建；无法重建时只能使用基于 GT 距离的近似可靠性软标签，并明确其并不等价于原始噪声真标签。

**缺失需求标签**：训练时利用已知删除区域或由“完整 GT 对观测点的覆盖差”构造**局部缺失证据**。必须排除自然边界；需要验证原 `hole_10` 生成方式、孔洞中心/半径/局部归一化标记是否可获得。

**恢复目标**：训练时使用干净 GT 中的已删除区域，约束附近输出点的几何位置与覆盖；测试时禁止借助 GT 产生候选。

### 3.5 建议损失（分阶段开启）

\[
\mathcal L_{M1}=\mathcal L_{FM}
+\lambda_r\mathcal L_{rel}
+\lambda_h\mathcal L_{hole}
+\lambda_{rec}\mathcal L_{local-rec}
+\lambda_{move}\mathcal L_{move}
\]

- `L_FM`：沿用原 PUFM 的 EMD/预匹配配对和原流匹配目标，不任意替换其目标定义。
- `L_rel`：可靠性 BCE / focal 或不平衡加权监督；避免正常点占比过大使模型全预测“可靠”。
- `L_hole`：候选区域需求的 BCE / soft regression；**标签仅在对应候选区域定义并有效时计算**。
- `L_local-rec`：孔洞内 GT 到输出的**单向覆盖项**＋候选输出到局部 GT 的准确性项；可以用局部双向 Chamfer，并分开统计两个方向。
- `L_move`：控制种子修正过大、切向/法向不合理位移；正常区域应更强地抑制不必要修正。

**风险保护**：不要一开始开启全部损失。先 `L_FM + L_rel`，确认可靠性头有识别能力；再加入缺失需求，最后打开受限恢复位移和局部几何损失。训练和验证中分别记录正常/噪声/空洞子集，防止“孔洞好了但正常样本坏了”。

### 3.6 M1 独立实验重点

- 指标：正常 A0 的 CD / F-score 不应大幅下降；D2/D7 的噪声/离群点残留应降低；C2 的孔洞 GT→预测点距离、覆盖率应改善；E1/E2 检查混合鲁棒性。
- 验证头的输出：可靠性直方图、可靠/不可靠点可视化、候选孔洞召回与误报、种子移动长度。
- 对照：仅共享几何编码、仅可靠性、仅候选缺失、可靠性＋缺失、加入位移引导。此处是**M1 内部小消融**，不是新增模块。
- 若最终只有 `r/h` 分类损失下降，但输出点云几乎没变化，说明分支没有实际参与生成，不能声称恢复有效。

## 4. 模块二 M2：重建需求驱动的动态点数分配（GDBA）

### 4.1 职责与原则

**固定总点数** `N=4n`，但允许区域间不均匀分配；目标不等于让所有高曲率区域获得更多点，而是学习**更多点是否能提升重建质量**。

M2 必须区分：

| 情况 | 优先策略 |
|---|---|
| 光滑且完整、覆盖充分 | 保留基础预算即可 |
| 高曲率且特征可靠 | 可以提高几何细节预算 |
| 噪声导致的伪高曲率 | 不应简单追加点数 |
| 光滑但存在真实孔洞 | 若上下文支持恢复，可提供额外候选点 |
| 稀疏而不确定的真实边界 | 保守配置，避免跨边界填充假面 |

### 4.2 分区方法

1. 在**输入点**上 FPS 选取 `K=ceil(n/32)` 个锚点；
2. 每个输入点分配给最近的一个 FPS 锚点形成**互斥区域**；
3. 区域内特征提取可使用重叠邻域；预算记账必须使用互斥归属以避免重复计数；
4. 对稀疏区域与小区域，防止“无点区域无法分配”的矛盾：M1 可以提供候选缺失锚点；M2 单独实验则只能在已观察区域及边界邻域自适应，不能凭 GT 凭空制造锚点。

### 4.3 重建需求评分：不使用单一手工权重

每区融合：

\[
z_j=[f_j^{PUFM},g_j^{local},g_j^{context},u_j]
\]

- `f_PUFM`：原始编码特征池化；
- `g_local`：区域内部几何复杂度、采样稀疏度、局部尺度；
- `g_context`：相邻区域特征差异、边界连贯性；
- `u_j`：可选的不确定度或区域质量估计（M2 单独模式也必须能计算）。

以小型 MLP/门控网络得到：

\[
s_j=f_{budget}(z_j)
\]

联合模式：**将 M1 的区域可靠度汇总和 `h_j` 作为额外输入**，但不能将 `s_j` 直接固定成曲率加权公式，也不能令 `s_j=h_j`（否则 M2 不具备独立学习功能）。

### 4.4 固定点数的预算公式

先为每区保留最低覆盖预算 `b_min,j`，再分配剩余：

\[
\widetilde B_j=b_{j}^{min}
+\left(N-\sum_k b_k^{min}\right)
\frac{e^{s_j/\tau}}{\sum_k e^{s_k/\tau}},
\quad \sum_j \widetilde B_j=N
\]

- `N=1024`（训练）或 `8192`（测试）；
- 示例 `K=8/64`，每区平均 128；`b_min≈64`、最大预算约 256 作为**初始化的保护边界**；
- `τ` 不能过低，初始趋近均匀分配，随后在验证集调节；
- 若某区域可用候选不足，应触发候选补充，不允许重复同一坐标凑点。

上述公式仍是**连续预算**。需要通过“裁剪到上下限＋最大余数法/受约束的整数化”得到 `B_j∈Z` 且严格满足 `sum B_j=N`；当某区达到上限，溢出的预算必须重新分配给可容纳区域。

**边界情况**：部分区域的自然几何面积可能不同，绝对均匀保底并非总是最优；第一版以固定保底保证安全，后续可以根据输入可见表面积或区域容量调整保底，但必须单独消融证明收益。

### 4.5 和 PUFM Midpoint 的接法：首推“预算感知的初始化”

不要采用“PUFM 已生成 8192 点后，再凭曲率随机删/复制”的做法。建议在 FM 积分**之前**完成预算分配：

1. 先按原始 PUFM 生成默认 Midpoint 种子池 `X_0`；
2. 把默认种子分配到互斥区域，得到各区原始数量 `n_j^0`；
3. 根据预算 `B_j` 对候选种子做**保留、局部补充或少量跨区重新配额**；
4. 局部补充点优先采用相邻可靠点的内插或有界几何外推；避免原点复制、无约束扰动；
5. 输出精确 `N` 个新的初始种子，送入**未改结构的原始 PUFM 速度场**；
6. 初期将预算偏移幅度限制在合理范围，逐渐放松。

形式为：

\[
X_0^{GDBA}=\operatorname{Allocate}(X_0,\{B_j\},\mathcal A)
\]

其中 `A` 为输入几何锚点/候选池，而非测试 GT。原始 Midpoint 的几何先验尽量保留；第一版不额外堆叠 M1b 的终点 CD，以免把收益归因搞混。

### 4.6 一个必须显式解决的工程问题：整数预算不可直接反传

“算出 Softmax 预算 → 四舍五入 → 改变每区点数”通常会切断预算头到最终 CD 的梯度。这是新方案**最主要的实现风险之一**。

建议采用**分两步的可执行方案**，而不是一句“端到端学习”带过：

**方案 A（优先、稳妥）：软预算代理训练＋硬预算生成**

- 在预算头训练初期保留连续 `\widetilde B_j`；
- 根据训练时 GT 与**冻结的基线输出**，为各区域构造可微的**覆盖需求代理目标**（例如局部 GT→预测点距离、局部阈值覆盖不足、点浪费情况），只用于训练；
- 用 softmax 分布拟合此代理目标，并添加熵/容量约束，确保预算不是永远均匀或全部集中；
- 推理时将 `\widetilde B_j` 严格整数化，再运行真实的 PUFM 初始化和生成；
- **必须用真实硬预算下的验证 CD/F-score 检查“软目标提升≠最终输出提升”的训练—推理差距**。

代理目标来自输出误差，而不是“曲率越高就应该采多少”的固定规则。它只是训练时的目标构造，**不是旧 Our1 的多阶段 GainNet 教师网络**；不要直接复用旧 GainNet 权重或缓存教师作为这版默认实现。

**方案 B（A 有效后再试）：可微候选权重／近似 Top-k**

- 每区构造有限规模的候选初始点池；
- 预测候选点权重或使用可微松弛得到“期望预算”；
- 若采用 Straight-Through / Gumbel 近似，必须检查梯度、采样方差以及硬选择后真实指标；
- 不要在第一个版本同时引入大规模候选池和复杂离散优化，以免显存、训练速度和归因失控。

> 不论哪种方案，**只有预算头确实学到了输入相关的不同分配，且真实整数预算推理改善了结果**，才可称为有效动态点数分配。

### 4.7 M2 监督与目标（初版）

\[
\mathcal L_{M2}=\mathcal L_{FM}
+\lambda_{CD}\mathcal L_{CD}
+\lambda_{cov}\mathcal L_{cover}
+\lambda_{bud}\mathcal L_{budget-proxy}
+\lambda_{reg}\mathcal L_{budget-reg}
\]

- `L_FM`：原 PUFM 流匹配损失，保证生成可学习；
- `L_CD`：干净 GT 的几何损失，严格保持所有模型一致的 GT；
- `L_cover`：以 GT→预测点的距离、多个阈值上的软覆盖统计实现，避免仅优化靠近已有表面的点；
- `L_budget-proxy`：仅在方案 A 中启用的区域需求软标签/代理误差；需要处理标签归一化和区域面积；
- `L_budget-reg`：避免预算塌缩、过度不均匀、区域预算剧烈变化；**不能强到强迫模型始终均匀**。

**建议开启顺序**：FM → 软预算代理 → 真实硬预算输出与 FM 联合适应 → 少量 `CD/cover` 联合精修。损失系数须通过验证集选取，不预设“多加损失一定更好”。

### 4.8 证明“真动态”必做的诊断

- `B_j` 的均值、标准差、最大/最小、熵、实际占比；
- 预算相对输入点云复杂度、孔洞需求、噪声置信度的相关性；
- 对同一物体不同退化条件，区域预算变化是否有合理对应；
- 把学习预算替换为**相同总点数的均匀预算**，其余权重和初始化尽可能固定；
- 与**固定曲率预算/固定密度预算**及“仅改变点初始化”的对照；
- 观察有多少点进入孔洞区域、是否在边界产生堆积，防止只用 CD 解释预算效果。

## 5. 两模块的联合方式（最后才做）

### 5.1 信息交互

M1 向 M2 提供的**附加条件**：

\[
\bar r_j=\operatorname{Pool}_{i\in \Omega_j}(r_i),\qquad h_j,\qquad u_j^{rec}
\]

联合预算头为：

\[
s_j=f_{budget}([z_j,\bar r_j,h_j,u_j^{rec}])
\]

- **M1** 可以先提示“这里的离群点不可信/这里可能有可恢复缺失”；
- **M2** 再判断“在全局有限预算下这里需要多给多少点”；
- **PUFM** 根据初始候选与可靠性条件进行坐标生成。

### 5.2 保护旧主干与独立性

- 首轮联合训练**冻结 M1**，仅微调 M2 和必要的轻量条件接口；
- 若结果稳定，再低学习率联合微调，避免 M1 可靠性语义被 M2 预算损失破坏；
- 在 M2 输入中进行 `M1 feature dropout`（仅训练），确保联合模式不是“完全依赖 M1”；
- 所有分支使用 `enable_m1` / `enable_m2` 单独开关，关闭两者时应严格回到原始 PUFM。

### 5.3 联合损失

初期仅使用模块各自已验证的损失组合，**不要在联合时新增第三种未验证的全局教师或复杂物理先验**。若 M1 与 M2 梯度发生明显冲突，先采用分阶段/冻结训练，不立即引入复杂多任务优化算法。

## 6. v3 数据准备与监督约束

**不要求重新生成整个 v3 数据集**；先检查是否具备下列必要字段：

| 检查项 | 用途 | 不具备时的处理 |
|---|---|---|
| 原始完整/干净 GT | FM、CD、覆盖评价 | 必须具备；不改变最终统一 GT |

| 空洞删除区域参数 / 掩码 | M1 缺失监督 | 在训练侧根据 GT 与观测近似估计；评测标签来源须透明 |
| 样本级 `object_id`、`condition`、`seed` | 对象级拆分与配对检验 | 必须核对，避免泄漏 |

**严格要求**：
- 对训练对象生成的辅助标签可以引用训练 GT；验证时只用验证 GT **评分和选择超参数**，不能喂给前向预测；测试时 GT 仅用于最终指标计算。
- 将 `A0/B2/C2/D2/D7/E1/E2` 的来源及退化强度写入 metadata；不根据测试表现重新修改冻结输入。
- 保证点云归一化、F-score 阈值与现有测试协议一致；现有评测 F-score 阈值为 **0.01**。
- **不使用熔池物理模型**参与 PU1K/ModelNet40 模块训练或公共数据测试。

## 7. 训练路线与 checkpoint 原则

### 前置阶段 P0：修复参照实验（必须）

当前 15 轮 B-extra 相对原 PUFM 的 CD-L1 退化：PU1K `0.018082→0.019497`，ModelNet40 `0.019988→0.021384`。在任何模块正式胜负判断前：

1. 核对续训起点 checkpoint、optimizer/scheduler 状态、学习率、EMD 匹配、梯度裁剪和保存权重是否正确；
2. 对同一验证集画出训练损失、验证 CD/F-score 随轮次变化；
3. 按验证集选模型，不能直接固定用 15 轮 `last.pt`；
4. 保留**未续训 PUFM**和**同续训预算 PUFM**两个对照；新模块必须与同预算对照比，也应检查能否优于未续训 PUFM。

### 阶段 P1：模块一独立训练

- 原始 PUFM 加 M1；M2 关闭，严格保留原预算；
- 初始化 M1 输出对生成的修正为零/极小；
- 第一步仅训练 M1 可靠性分支；第二步训练缺失需求；第三步逐渐解冻小幅生成引导；
- M1 超参数优先使用训练/验证集，不基于80物体测试子集来回试错。

### 阶段 P2：模块二独立训练

- 原始 PUFM 加 M2；M1 关闭；
- 第一阶段学习软预算需求，记录与均匀预算的差异；
- 第二阶段真实预算整数化后联合训练/适应 FM；
- 显式检查预算头是否有有效梯度/是否输出常数；
- 学习预算与原 Midpoint 的兼容性是核心验收项。

### 阶段 P3：联合训练

- 先冻结 M1，仅训练 M2 联合条件；之后小学习率联合；
- 保留 M1-only、M2-only、Joint 的完整验证日志；
- 若 Joint 比单模块差，先检查 `r/h` 的尺度与门控，而不是增加第三模块。

### 训练预算的公平控制

**不要仅用“同样轮数”定义公平**：至少报告相同训练样本数/更新步数、batch、优化器、学习率策略、初始 checkpoint、训练时间和参数量。可以设“相同步数主对照”＋“各模型独立验证择优”的补充对照，两者分别解释。PUFM++/SPU 是不同生成流程，应同时报告推理步骤和耗时，避免将其默认看作同结构单模块消融。

### 多 seed 建议

对最终 M1、M2、Joint 和关键对照使用不少于 3 个 seed（可从 3 开始），同时对物体进行配对统计/Bootstrap 置信区间；小于 1% 的 CD 提升尤其谨慎。不要为单一 seed 的微小收益提出“稳定显著提升”的表述。

| 类别 | 主要指标 | 想回答的问题 |
|---|---|---|

| 动态分配 | 预算熵、分区点数分布、有效覆盖 | 是否真正实现输入相关的动态分配 |
| 效率 | 参数量、峰值显存、端到端时间、生成步数 | 改善是否有合理代价 |

`P2F` 仅在有可信表面/法向参照且计算协议一致时加入。原整物体测试暂未启用，不应凭空补写结果。对于动态采样，**可额外报告局部几何与曲率保持**，但不能拿自行设计的指标替代 CD/F-score/HD 的公平比较。

## 9. 关键失败模式、诊断和退出条件

| 风险 | 典型症状 | 诊断 | 初步应对 |
|---|---|---|---|
| `B-extra` 本身退化 | 所有新模块都接近或好于退化 B-extra，但不如原 PUFM | 同步追踪验证 CD/F-score、checkpoint 选择 | 先修训练策略，再比较结构 |
| M1 只学会分类 | `r/h` 预测看似准确，但输出无变化 | 比较关闭/开启引导时的点云与指标 | 接入有界种子残差或条件特征 |
| M1 误填真实边界 | 薄壁处造面、空隙被填满 | 细结构与真实开口可视化 | 加强跨侧一致性和不确定度门控 |
| M1 噪声放大 | 高曲率噪声处点数堆积 | D7、局部误差及可靠度图 | 可靠性只作抑制、不要删掉真实边缘 |
| M2 预算恒定 | `s_j` 基本相同，预算不变 | 预算熵、梯度范数、变化统计 | 检查代理目标/温度/正则是否太强 |
| M2 预算塌缩 | 少数区域占据大部分点 | min/max、局部覆盖缺失 | 启用保底与上限、减小集中程度 |
| M2 不可导 | 预算头无梯度；只有生成器在学 | 参数梯度检查、软硬预算差异 | 先用软预算代理训练，别误称端到端 |
| 初始分布破坏 FM | CD、F-score 全面下降 | 对比原 Midpoint 与动态初始化的初始距离分布 | 缓慢引入配额偏移、保留原种子 |
| 跨尺度不泛化 | Patch 验证好，2048→8192 差 | 对比 K、邻域距离尺度、归一化 | 使用相对距离/分区比例、跨点数验证 |
| CD 好但 F-score 差 | 某些点更准确，但整体覆盖不足 | 分解 pred→GT 与 GT→pred、阈值 P/R | 强化覆盖并减少区域点浪费 |
| 联合后互相拖累 | M1/M2 单独好，Joint 差 | 冻结 M1、对比 `h/r` 输入开关 | 条件门控、特征 dropout、低学习率联合 |

**建议阶段门槛（仅作为研发决策，不是论文指标宣称）**：
- P0：正常续训对照可复现、验证无系统性退化；
- M1：在相关退化条件上稳定改善，正常 A0 无明显牺牲；
- M2：相同 N、相同 GT 下，学习预算优于均匀/手工预算，且预算不是常数；
- Joint：至少不应牺牲两个独立模块的主要优势；否则回到接口而非堆新结构。

```python
# X: (B, n, 3); N = 4*n
F = pufm.encode(X)

r = h = m1_context = None
if enable_m1:
    r, h, m1_context = ragr(X, F)

if enable_m2:
    region = partition_by_fps(X, points_per_region=32)
    logits = gdba(X, F, region, r=r if enable_m1 else None,
                  h=h if enable_m1 else None)
    budgets = exact_integer_budget(logits, total_points=4 * X.shape[1],
                                   min_ratio=0.5, max_ratio=2.0)
    x0 = midpoint_with_region_budget(X, region, budgets)
else:
    x0 = pufm.original_midpoint(X, target_points=4 * X.shape[1])

if enable_m1:
    x0 = ragr.bounded_seed_refine(x0, X, r, h, m1_context)

Y = pufm.original_flow_integrator(x0, F, condition=m1_context)
assert Y.shape[1] == 4 * X.shape[1]
```

## 11. 最终创新性表述（论文写法草案）

### 创新点 1：可靠性感知的缺失引导点云恢复

针对非均匀、含噪及局部缺失点云中观测可靠性与结构恢复需求难以联合判断的问题，设计基于多尺度局部几何及跨区域上下文的可靠性—缺失联合感知机制。网络对输入点可靠性与候选恢复区域需求进行协同估计，以受约束的初始化引导参与 PUFM 流匹配重建，降低不可信观测对生成过程的干扰，并改善局部缺失区域的恢复质量。

### 创新点 2：重建需求驱动的固定预算动态点数分配

针对固定采样规则难以兼顾几何细节、缺失恢复与整体覆盖的问题，设计以区域重建需求为依据的可学习点数预算分配机制。在固定总输出点数下联合考虑几何复杂度、局部覆盖和恢复置信度，使用覆盖保底与预算约束调节区域采样密度，并与 PUFM 的 Midpoint 初始化协同，以提升复杂退化场景下的重采样精度和点数利用效率。

**关于“自主创新”的谨慎说明**：以上仅是方案的研究假设。PUFM++ 的终点扰动、SPU-IMR 的 Mask-recovery、以及既有自适应分配/重建工作都涉及相关思想；最终是否具有充分独创性，需完成结构对照、文献查重式综述、关键机制消融和有效性验证，不应在方案阶段就宣称“完全没有人做过”。
